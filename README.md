# 프론트엔드 신입/고졸 채용공고 필터링 프로젝트

사람인/잡코리아/원티드/랠릿의 프론트엔드 신입 채용공고 중
고졸 지원이 실제로 가능한 공고만 걸러내고, 잡플래닛 평점을
함께 정리하는 것을 목표로 하는 프로젝트입니다.

## 진행 상태

| 사이트 | 상태 | 방식 |
|---|---|---|
| 사람인 | ✅ 구현 완료 | Open API |
| 잡코리아 | ⬜ 스텁 | Open API (이용신청 필요) |
| 원티드 | ⬜ 스텁 | 크롤링 예정 (robots.txt 확인 필요) |
| 랠릿 | ⬜ 스텁 | 오픈 API 여부 확인 필요 |
| 잡플래닛 평점 | ⚠️ 보류 | 이용약관상 리스크 커서 대안 검토 중 |

## 핵심 아이디어: 2단계 학력 필터링

사람인의 `required-education-level`(edu_lv) 코드는 사람인이
구조화해둔 값일 뿐, 실제 공고 본문의 우대사항에는 "대졸 이상
지원 가능" 같은 문구가 별도로 있는 경우가 많습니다.

1. **1차 (API)**: `edu_lv=0,1,6`(학력무관/고졸/고졸이상)으로
   구조화된 데이터 기준 후보군을 뽑음
2. **2차 (상세페이지 텍스트 키워드)**: 후보 공고의 상세페이지를 열어
   `config.EXCLUDE_PHRASES`에 정의된 문구가 있는지 확인,
   있으면 실제로는 고졸 지원이 어려운 공고로 표시
3. **3차 (LLM 보조 검증, 선택)**: `.env`에 `OPENAI_API_KEY`를
   설정하면, 2차 키워드 매칭에 걸리지 않은 공고에 대해 OpenAI
   (`gpt-4o-mini`)로 본문을 재검토해 표현이 다른 "사실상
   대졸 이상" 공고를 추가로 걸러냄. 키가 없으면 이 단계는
   건너뛰고 키워드 매칭 결과만 사용함

## 설치

```bash
pip install -r requirements.txt
cp .env.example .env
# .env 파일에 사람인 Open API access-key 입력
```

access-key는 https://oapi.saramin.co.kr 에서 이용신청 후
승인받아 발급받을 수 있습니다.

(선택) LLM 보조 검증을 쓰려면 `.env`에 `OPENAI_API_KEY`도
입력하세요. https://platform.openai.com 에서 발급받으며 종량제
과금입니다. 설정하지 않으면 키워드 매칭 기반 2차 검증만 동작합니다.

## 실행

```bash
python main.py
```

결과는 `data/saramin_high_school_eligible_jobs.csv`에 저장됩니다.

## 폴더 구조

```
.
├── config.py              # 검색 키워드, 학력 코드, 제외 문구 등 설정
├── main.py                # 실행 진입점
├── crawlers/
│   ├── saramin.py          # 사람인 Open API (구현 완료)
│   ├── jobkorea.py         # 스텁
│   ├── wanted.py           # 스텁
│   ├── rallit.py           # 스텁
│   └── jobplanet.py        # 스텁 (법적 검토 필요)
├── filters/
│   ├── education.py         # 2차 학력 검증 필터 (키워드 매칭)
│   └── llm_verify.py        # 3차 LLM 보조 검증 (선택, OPENAI_API_KEY 필요)
└── storage/
    └── csv_writer.py        # CSV 저장
```

## 법적/약관 관련 주의사항

- **사람인**: 정식 Open API를 사용하므로 이용약관 범위 내에서 안전
- **잡코리아**: 자체 Open API가 있으나 개인/일반 기업은 승인이
  거부될 수 있음 — 승인 여부 확인 후 진행
- **원티드/랠릿**: 공개 API가 없어 크롤링이 필요할 가능성이 높음.
  반드시 각 사이트의 robots.txt와 이용약관을 확인하고, 요청 간격을
  충분히 두어 서버 부담을 최소화할 것. 상업적 이용 시 리스크가
  개인/학습 목적보다 훨씬 커짐에 유의
- **잡플래닛**: 평점/리뷰가 유료 열람 콘텐츠 성격이 강하고 크롤링을
  명시적으로 금지하는 경우가 많아 이 프로젝트에서 법적 리스크가
  가장 큰 영역. 구현 전 제휴/API 문의 또는 대체 데이터 소스를
  먼저 검토할 것
